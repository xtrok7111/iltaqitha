# التقطها

مشروعي النهائي في معسكر مسار القمة مسار التقنيات الناشئة

الفكرة جاتني من شي يصير معي كل مره اخلص التمرين العملي وبعدين انتبه اني نسيت اصور خطوة مطلوبة في التقرير

واذا قفلت البرنامج بعض النتايج تروح زي رسالة ان السيرفر شغال فاضطر ارجع اعيد التمرين كله عشان صورة وحدة بس

فسويت التقطها

تفتحه جنب البرنامج اللي تشتغل عليه وتلصق فيه تعليمات التمرين ويطلع لك الخطوات اللي تبي صور ووش لازم يبان في كل صورة

كل ما تخلص خطوة صورها وارفعها وهو يقولك اذا الصورة تمام ولا ناقصها شي

وقبل ما تقفل البرنامج اضغط زر تأكد قبل ما تقفل البرنامج عشان تتطمن انك ما نسيت شي

## طريقة التشغيل

```
pip install -r requirements.txt
streamlit run app.py
```

بعدها حط الـ API key حق Gemini في الخانة اللي على الجنب

واذا ما عندك مفتاح عادي يشتغل بس بيطلع الخطوات من كلمة screenshot او صور والصور بتراجعها انت

ترا النسخة المجانية من Gemini لها حد طلبات بالدقيقة فاذا علق شوي اصبر عليه لانه يعيد المحاولة لحاله

## كيف جربته

سويت 10 صور لتمرين لينكس 4 منها كاملة و 6 كل وحدة فيها غلط مختلف زي الناتج بدون الامر او صلاحيات غلط او صورة مغبشة

وكتبت سكربت يشغل التطبيق عليها ويقارن مع النتيجة الصح اللي حاطها في tests/expected.csv

```
python tests/make_test_images.py
set GEMINI_API_KEY=...
python tests/test_accuracy.py
```

طلع 10 من 10 صح وكشف الست الناقصة كلها

بس الصور هذي انا اللي سويتها وواضحة والصور الحقيقية ممكن تكون اصعب فالرقم هذا مو نهائي

النتايج كاملة في tests/results.csv
