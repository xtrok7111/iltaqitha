تمرين: أساسيات لينكس - الملفات والصلاحيات

1. افتح التيرمنال ونفذ الأمرين whoami و hostname، وخذ screenshot يبين الأمرين والناتج.
2. أنشئ مجلد باسم lab1 بالأمر mkdir lab1 وادخل عليه بالأمر cd lab1.
3. أنشئ ملف notes.txt بالأمر touch notes.txt ثم نفذ ls -l وصوّر الشاشة بحيث يظهر الملف.
4. غيّر صلاحيات الملف بالأمر chmod 640 notes.txt ثم نفذ ls -l مرة ثانية وخذ screenshot يبين إن الصلاحيات صارت -rw-r-----
5. شغّل السيرفر بالأمر python3 server.py، راح يطلع لك Server running on port 8080. صوّر الشاشة والسيرفر شغال لأن الرسالة تختفي إذا قفلته.
6. اقفل السيرفر بـ Ctrl+C.
